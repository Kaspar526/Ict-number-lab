# 數據表示實驗室

中四 ICT 互動教學網站：二進制、十進制、十六進制轉換，以及二補碼。

## GitHub Pages

在 Settings → Pages，選擇 Deploy from a branch，使用 main 分支及 /(root)，再按 Save。

## 離線使用

下載 ZIP 並解壓縮，以瀏覽器開啟 index.html。所有計算在瀏覽器執行，不需要 API、帳戶或資料庫。

## 功能

- 六個方向的進制轉換，逐步顯示位值、除法餘數及四位分組。
- 上一步、下一步、自動播放。
- 4、8、16 位元二補碼，展示取反、加一、進位與負權重驗證。
- 字長範圍檢查、教材例子與響應式版面。
