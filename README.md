# 數據表示互動學習平台

香港中四 ICT 遊戲化教學網站，使用繁體中文。

## 學習內容

- 8-bit 位元實驗台及權重組合任務。
- 二進制、十進制、十六進制六向轉換；短除法在商小於基底時停止。
- 二進制轉十六進制逐組動畫。
- 一補碼、二補碼及取反加一動畫。
- 反向解碼：先取反、再加一、計算絕對值、加回負號。
- 溢出動畫：加數 A、加數 B、藍色進位列、橫線、結果；顯示額外第九位及捨去原則。
- 14 道 DSE 精選題、即時回饋及 XP。

## 使用

下載並解壓縮後，用瀏覽器開啟 `index.html`。所有網站檔案須放在同一資料夾，不需要 API 或資料庫。作答進度只保留至重新載入。

## GitHub Pages

在 Settings → Pages 選擇 Deploy from a branch，使用 `main` 分支及 `/(root)`。如原有設定已啟用，推送後會自動更新。

## 檔案

- `index.html`：頁面入口
- `style.css`：樣式
- `app.js`：學習區與題庫
- `animation.js`：進制轉換動畫
- `teaching.js`：補碼與溢出動畫
- `reverse.js`：反向解碼動畫

DSE 題目版權屬香港考試及評核局；教學解說並非官方評分方案。
